# 开源与第三方披露

本作品源码以参赛仓库发布：https://github.com/NineSense9/Veriflow  

题面为原创，题型谱系参考公开 ACM 训练体系（实现、二分、DP、图等），**未搬运** Codeforces / 洛谷 / 牛客 / LeetCode 原题题面。

## 使用的开源组件

| 组件 | 用途 | 许可（以各项目官方为准） |
|---|---|---|
| Python | 运行时 | PSF |
| FastAPI / Pydantic / Uvicorn | HTTP 与 Schema | MIT |
| Next.js / React | 训练站 | MIT |
| Monaco Editor | 代码编辑 | MIT |
| @xyflow/react (React Flow) | 出题画布 | MIT |
| Docker / debian | 评测隔离 | Apache-2.0 / DFSG |
| nginx | 反向代理 | 2-clause BSD |
| pytest | 测试 | MIT |

未对上述组件做闭源修改后伪装原创。

## 模型服务

- 可选接入 DeepSeek 官方 OpenAI 兼容 API（`deepseek-flash`）。  
- **核心判定不依赖该 API**：对错由静态检查与 Docker 给出。  
- Key 仅存在于服务器 `.env`，不进入前端与 git。  
- 无 Key 时 Compiler / Solver / Tutor 降级为本地启发式，功能可演示。  

## 数据与隐私

演示库为预置题包与本地提交记录，不含真实学生个人信息。评委账号口令见部署说明，正式提交前应更换 `DEMO_PASSWORD`。
