# VF1002 课表前缀和

课表记下了 n 天的课时。有 q 次询问，每次问某一段连续日期的课时总和。

## 输入

第一行两个整数 n 和 q（1 ≤ n, q ≤ 100000）。

第二行 n 个整数 a_1 … a_n（0 ≤ a_i ≤ 1000000000），表示每天的课时。

接下来 q 行，每行两个整数 l r（1 ≤ l ≤ r ≤ n），表示一次询问，下标从 1 开始，含两端。

## 输出

共 q 行，每行一个整数，表示区间 [l, r] 的课时和。

和可能很大，C++ 请使用 64 位整型。

## 样例

输入

```
5 2
1 2 3 4 5
1 3
2 5
```

输出

```
6
14
```
